# База даних інформаційної системи обліку технічного обслуговування авіаційного обладнання (`avia_mro`)

Курсова робота з дисципліни **«Бази даних»**  
**Заклад освіти:** Київський авіаційний інститут (КАІ), Факультет комп'ютерних наук та технологій, Кафедра інженерії програмного забезпечення  
**Спеціальність:** F2 «Інженерія програмного забезпечення»

---

## 1. Опис проєкту та межі системи

Репозиторій містить повний комплект SQL-скриптів, тестових даних, демонстраційних сценаріїв та автоматизованих перевірок для реляційної бази даних обліку технічного обслуговування (ТО) повітряних суден та авіаційних агрегатів.

**Основні функціональні можливості:**
* облік парку повітряних суден (`aircraft`, `aircraft_types`) та їхнього сумарного нальоту;
* контроль міжремонтного ресурсу серійних агрегатів (`components`, `component_types`) із визначенням стану ресурсу (`ok`, `warning`, `critical`);
* планування та ведення нарядів на ТО (`work_orders`, `maintenance_types`) з контролем життєвого циклу статусів (`planned` → `in_progress` → `completed` / `cancelled`);
* облік виконаних робіт (`work_order_tasks`), виконавців (`employees`) та списання запасних частин зі складу (`spare_parts`, `part_usage`);
* реєстрація та відстеження усунення виявлених дефектів (`defects`);
* автоматичний аудит змін статусів нарядів (`audit_log`) та розмежування прав доступу на рівні ролей (`mro_engineer`, `mro_analyst`).

---

## 2. Середовище розгортання та версії

* **СУБД:** PostgreSQL 16 (перевірено на `PostgreSQL 16.16`)
* **Контейнеризація:** Docker / Docker Compose
* **Клієнтські інструменти:** `psql`, JetBrains Rider (Database Tools) / DBeaver
* **Додаткові розширення PostgreSQL:** не потрібні (використовуються стандартні засоби PostgreSQL 16)
